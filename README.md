# 字间 · 汉字崩解实验室

一个不依赖后端的交互网页：把浏览器字体渲染后的汉字按像素连通区域或更细尺度分解为粒子，并让用户通过点击、触摸和拖动改变文字结构。

## 本地预览

```bash
python -m http.server 4173
```

打开 `http://localhost:4173`。

## 拆分与降级策略

- 每个非空白字符先绘制到 2× 离屏画布。
- 使用 8 邻域连通域分析识别视觉上分离的部件。
- 过滤抗锯齿噪点，并把细小像素岛合入主部件。
- 如果某个字只有一个可靠连通域，则保留整字作为一个粒子；界面会显示降级数量。
- “分解尺度”可在整字、连通部件、近似笔画和细小碎屑之间变化。
- 六种预设会写入对应的物理参数，之后仍可逐项微调。
- 腐烂模式会累计部件损伤；水面模式会使用手势移动方向和速度。
- 当前崩解状态可以导出为完整、透明背景、二倍分辨率的 PNG。

所有文本和图像分析都在当前浏览器内完成。
