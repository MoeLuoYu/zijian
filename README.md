# 字间 · 汉字崩解实验室

一个不依赖后端的交互网页：把浏览器字体渲染后的汉字按像素连通区域或更细尺度分解为粒子，并让用户通过点击、触摸和拖动改变文字结构。

## 本地预览

```bash
python -m http.server 4173
```

打开 `http://localhost:4173`。

## 拆分与降级策略

- 每个非空白字符先绘制到 2× 离屏画布。
- 使用 8 邻域连通域分析识别视觉上分离的部件。
- 过滤抗锯齿噪点，并把细小像素岛合入主部件。
- 如果某个字只有一个可靠连通域，则保留整字作为一个粒子；界面会显示降级数量。
- “分解尺度”可在整字、连通部件、近似笔画和细小碎屑之间变化。
- 七种预设会写入对应的物理参数，之后仍可逐项微调；微风会大范围轻拂文字，松手后逐渐复位。
- 腐烂模式会累计部件损伤；水面模式会使用手势移动方向和速度。
- 背景默认为纯白色，可选择底色、上传图片并选择完整显示或居中裁剪；文字颜色即时生效。
- 当前崩解状态可导出为二倍分辨率的透明 PNG，或将文字与当前背景合成一张 PNG。
- 撤回按一次完整手势记录，最多保留 20 步，包括侵蚀损伤。撤回后暂停，点击“继续”恢复运动；复位或重新生成会清空记录。

所有文本和图像分析都在当前浏览器内完成。

## 发布更新

上传 `index.html`、`styles.css` 和 `app.js` 到原站点根目录，覆盖同名文件即可；无需构建或后端服务。HTML 已使用 `v=5` 资源版本号。

如果腾讯云项目已关联 GitHub 的 `main` 分支，推送后请在腾讯云控制台核对构建和部署状态；否则需手动上传这三个文件。发布后刷新网页，确认出现“导出带背景 PNG”和“微风”按钮。
